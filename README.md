# Metroid Subzero

A personal Godot fangame inspired by Metroid, created as a learning project for game development and software engineering.

## About the Project

This project is a fan-made tribute to the Metroid series, built to explore game design, level creation, character mechanics, and engine workflow in Godot. The main character is Rundas, a side character from the Metroid saga known for his ice powers, ice beam, ice pillars, and stylish sliding movement.

Revisit the Zebes planet to investigate the crash of a mysterious spaceship. This time, the mission is guided by the bounty hunter Rundas.

## Project Notes

This is a non-profit, personal project created for learning, experimentation, and creative exploration.

## Controls

- `W`, `A`, `S`, `D` — move the player
- `Space` — jump
- `J` — shoot
- `K` — dash
